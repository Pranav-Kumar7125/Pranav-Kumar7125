| **Oct 2025 - Jan 2026** | **AI-Based Intrusion Detection for Wireless Sensor Networks** | ICNCDA 2026, University of Essex · [Certificate](https://drive.google.com/file/d/1-P6wViBBZ8ZeGf8nQ3ihYFHlUqY09-5u/view?usp=drive_link) | Designed **IDFSWSN-DRL**: Temporal Convolutional Networks + Multi-Head Attention with Gazelle Optimization Algorithm feature selection (~68% smaller feature space). **99.09% accuracy** on WSN-DS, ahead of Naïve Bayes and Random Forest.
